# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| < 0.1 | No |

## Reporting a vulnerability

Do not disclose vulnerabilities in public issues, pull requests, or discussions.

Report privately through one of these channels:

- GitHub Security Advisories:
  `https://github.com/jaws777/options-ats-core/security/advisories/new`
- Security contact email:
  `security@jaworski.dev`

If you accidentally posted sensitive material publicly, contact maintainers
immediately and request redaction.

## Intake expectations and SLA

- Acknowledgement target: within 2 business days
- Initial triage target: within 5 business days
- Coordinated disclosure target: within 90 days where practical

## Disclosure and handling policy

- Secret leaks and exploit details are handled private-first.
- Public communication is sanitized and non-attributive by default.
- Reporter identity is kept confidential to the extent practical.
- Retaliation for security reporting is prohibited.

## What to include in a report

- Impact and affected area
- Reproduction steps or proof-of-concept
- Affected version and platform
- Suggested remediation if known

See [MAINTAINER_RESPONSE.md](MAINTAINER_RESPONSE.md) for incident handling and
appeal process.
